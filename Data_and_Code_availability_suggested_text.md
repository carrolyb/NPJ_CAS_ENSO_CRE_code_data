# Suggested Availability Text

## Data availability

The CERES FluxByCldTyp-Day Terra-Aqua MODIS Edition 4.1 data used in this study are publicly available from the NASA CERES project at https://ceres.larc.nasa.gov/data. The product DOI is https://doi.org/10.5067/Terra-Aqua/CERES/FluxByCldTyp-DAY_L3.004A. The monthly Nino3.4 index used to define ENSO phases was derived from the NOAA Climate Prediction Center ERSSTv5 monthly Nino indices, available at https://www.cpc.ncep.noaa.gov/data/indices/ersst5.nino.mth.91-20.ascii. The processed figure-level source data used to generate the main and supplementary figures are available in the public GitHub repository at https://github.com/carrolyb/NPJ_CAS_ENSO_CRE_code_data.

## Code availability

The Python scripts used to generate the main and supplementary figures, together with key processing scripts, are available in the public GitHub repository at https://github.com/carrolyb/NPJ_CAS_ENSO_CRE_code_data. Large intermediate CERES processing files are not included because the original CERES and NOAA CPC data are publicly available from the sources listed above.
