Figure 3. ENSO-associated reorganization of cloud-type occurrence across the tropical Pacific using a +/-0.5 C Nino3.4 definition. Panels show El Nino minus La Nina cloud-fraction anomalies for the tropical Pacific (TP), western Pacific (WP), central Pacific (CP), and eastern Pacific (EP). Outlined blocks indicate the closed five-group cloud classification used by later pathway diagnostics. Black dots mark cloud-type cells whose 95% moving-block-bootstrap confidence intervals exclude zero.
